# Bug Reports

This folder contains examples of bug reports created during QA training and self-study practice.

The reports include:

UI bugs
Localization issues
Functional defects
Gameplay and animation issues
Cross-platform testing examples

Each bug report contains:

Summary
Environment
Steps to Reproduce
Actual Result
Expected Result
Severity/Priority (where applicable)

Testing platforms:

Windows
Web Applications
Desktop Games

Tools and approaches used:

Manual Testing
Exploratory Testing
UI Testing
Localization Testing
Cross-Browser Testing
