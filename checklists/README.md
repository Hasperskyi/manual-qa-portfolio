# Checklists

This folder contains examples of QA checklists created during QA training and practical testing exercises.

The checklists were used for:

Functional Testing
UI Testing
Cross-Browser Testing
Localization Testing
Web and Desktop Application Testing

Included examples demonstrate:

Verification of interface elements
Validation of application behavior
Browser compatibility checks
Tracking of test execution results
Identification of failed and passed test conditions

Tools and environments:

Google Chrome
Microsoft Edge
Windows OS
Excel-based QA documentation

The purpose of these checklists is to ensure structured and consistent testing coverage during manual QA activities.
