# Test Cases

This folder contains examples of manual test cases created during QA training and practical testing exercises.

The test cases cover:

Functional Testing
UI Validation
Input Validation
User Interaction Testing
Web and Desktop Application Testing

Included materials demonstrate:

Test scenario design
Preconditions and expected results
Step-by-step verification processes
Structured manual testing approaches

The purpose of these test cases is to ensure reliable verification of application functionality and user workflows.
